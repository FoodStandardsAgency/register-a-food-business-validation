# Modifying an existing validation function

To update an existing validation function:

- update the unit tests to cover the new expected behaviour
- update the function implementation
- publish a new package version if the repository is released as an npm package

## Steps:

1.  Update the unit tests for the function. For more information, see [Writing unit tests](./writing-unit-tests.md).
2.  Update the validation function implementation in its source file.
3.  Re-publish the validation package if required. For more information, see [Re-publishing the package](./republishing-the-repository-as-an-npm-package.md).
